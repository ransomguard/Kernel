# RansomGuard v0.3.2 — SelfProtect 로그 결함 수정



`SelfProtect.c`의 로그 호출 한 줄이 함수명 없이 시작해 로그가 출력되지 않던

결함을 수정한 버전입니다. 기능 변경이 아닌 진단 결함 수정입니다.



**변경일:** 2026-09-23

**이전 버전:** `v0.3.1_verification`



---



## 수정 내용



`SelfProtect.c`의 `ObRegisterCallbacks` 실패 로그가 `ARW_LOG` 접두사 없이

괄호로만 시작해, 컴파일은 통과하지만 콤마 연산자로 해석되어 로그가 출력되지

않았습니다. 콜백 등록 실패 시 `/INTEGRITYCHECK` 힌트를 포함한 진단이

유실되던 문제입니다.



| 파일 | 변경 |
|---|---|
| SelfProtect.c | 로그 호출 한 줄에 `ARW_LOG` 접두사 복구 (1줄 추가, 1줄 삭제) |



`ResponseEngine.c`의 v0.1.1 수정(동일한 접두사 누락 복구)과 같은 형태입니다.

같은 결함이 자기보호 모듈에 남아 있던 것을 정리했습니다.



---



## 확인



- 최소 변경: 해당 한 줄 외 다른 코드는 손대지 않았습니다.

- 인코딩 보존: UTF-8 BOM + CRLF 유지.

- 컴파일 영향 없음: 로그 접두사 추가는 이미 배포 이력이 있는 형태로,

&#x20; 빌드 결과에 영향을 주지 않습니다.
