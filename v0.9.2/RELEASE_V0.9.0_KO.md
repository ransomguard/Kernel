# Kernel v0.9.0 — 2026-11-18

v0.8.0 폴더를 보존하고 최신 소스를 별도 추가합니다. INF DriverVer와 WDK StampInf는 모두 0.9.0.0입니다.

## 변경

- 이벤트 수집/배치 수신과 큐 계수 진단, 소비자 인계·드라이버 교체 시 유실 및 큐 비움 추적 보강.
- 프로세스 세대/신호와 종료 대상 확인, 파일 필터 관측 및 사용자 모드 연동 보강.
- 복구 v0.5.0 resident 수집기와 함께 필터 연결 전 수집기 준비 확인, 교체 전 drain, 중단 구간 기록.
- 기존 FastPath 차단, 실제 프로세스 이미지 기반 위험 명령 판단, PID+생성시각 종료 검증 및 기존 증거를 유지.

## 검증 범위

현재 소스의 동작 변경은 이전 VM 검증에서 사용했습니다. 12만 write 호출 부하 시험에서 추가 커널
dropped/flushed는 0이었고 과거 누적 유실 51,879는 남겼습니다. 이는 무제한 부하에 대한 무손실 보장이 아닙니다.
실제 자동 Track A(무해한 실행 파일 시험), Track B 실제 JEV 판정, 종료 확인, 승인 12개 파일 VSS 복구와 UI ACK는
[restore v0.5.0 검증 기록](https://github.com/ransomguard/restore/blob/main/v0.5.0/docs/V0_5_0_RELEASE_KO.md)에 정리합니다.

**이번 v0.9.0.0 버전 메타데이터로 생성한 서명 패키지를 새로 VM에 설치한 기록은 별개입니다.**
GitHub에는 소스를 올리며 기존 VM의 시험 서명 인증서/개인 키/설치된 드라이버 바이너리를 배포하지 않습니다.
드라이버 교체/재부팅 동안의 관측 공백은 coverage gap으로 표시해야 하며 카운터 초기화로 숨기지 않습니다.

Windows x64 시험 VM 전용 개발 배포입니다. 호스트에 설치하지 않습니다.
오래된 README 아래쪽과 과거 릴리스 파일은 당시 기록이며 현재 상태와 혼동하지 마세요.
