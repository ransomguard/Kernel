# Kernel v0.9.2 — Ransom0 통합 시험판

현재 설치본의 Core 자기보호 수정 소스와 기존 Filter 소스를 함께 보관합니다. 이전 v0.9.1 폴더는 보존합니다.

- Core 실행 바이너리 SHA256: 72d2b0b891a7a9f6f5e625a5afdcb8e3493cc79195fe8b1b35053cfa25518c68
- Filter 실행 바이너리 SHA256: 088f92660dfa263b94654cb8f46ab39a523678ceb46a1822354ce84a4d0ae38b
- 별도 rename-completion 개발 Filter는 이번 설치본에 포함되지 않습니다. 확장자 변경 시도와 완료를 모두 실측한다고 주장하지 않습니다.
- 버전 폴더는 소스 스냅샷 이름입니다. INF/ABI 값을 임의로 올려 재서명 패키지인 것처럼 만들지 않았습니다. Microsoft 배포 서명/정식 altitude 미확보 시험판입니다.
- 급격한 이벤트 부하의 추가 버퍼/배치 변경은 restore v0.5.3의 사용자 모드 수집기에 있습니다. 커널 큐가 무한해진 것이 아닙니다.
